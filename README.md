## Blood Donation System ##

This system is a simple Blood Donation System built by using Core PHP and Mysql with Bootstrap 5.3.It uses to view the donor details and register as a donor and it can be perform the admin to get the details of the registered donors and manage it.


## Features ##

- Blood Donation System
- User Authentication Login
- Register Donor
- Delete Donor
- Update Donor

## Installation ##

1. Clone the repository into your PHP web server's document root.
2. Configure the MySQL connection in `db.php` for your environment.
3. Start the web server and MySQL. Opening the application creates the database and tables.
4. Open `login.html`, select **Sign Up**, and register the first admin account.

## Usage ##

1. Open `home.html` in your browser
2. Submit the donor registration form.
3. Sign in with an admin account to view and manage donors.

## Login ##

1. Open `login.html` in your browser.
2. Register an admin account using **Sign Up** if you do not already have one.
3. Enter that account's email and password, then click **Login**.
